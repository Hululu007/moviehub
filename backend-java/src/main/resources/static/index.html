找源指南 检索方法，不托管任何源

这里只给检索入口和判断方法。点按钮会在新标签页打开对应搜索，结果自行甄别；本站不保存、不镜像任何第三方源。

① 影视点播源 苹果CMS 采集接口

要找的是形如 https://站点/api.php/provide/vod/ 的接口，不是网页地址。

检索词

怎么判断能用：浏览器直接打开 接口?ac=list&pg=1，返回 JSON 里出现 "list" 或 "class" 才算通。回到上方表格点「测速」也能验证。

② 电视直播源 M3U8 / M3U 播放列表

要找的是频道播放列表或单条直播流地址。

检索词

怎么判断能用：打开地址应返回以 #EXTM3U 开头的文本；单条流用播放器试播，能出画面才算数。注意区分「列表地址」和「单条流地址」，填错位置会全组失效。

③ 音乐音源 LX / 洛雪 JS 脚本

这类是 JS 脚本地址，失效极快，看最近提交时间比看星标有用。

检索词

怎么判断能用：打开脚本地址应返回 JS 文本（不是 404 页面）；脚本都靠 jsDelivr / GitHub Raw 分发，链接带 @latest 或 main 的更容易长期有效。

④ 通用检索技巧
  • 搜代码比搜标题准：GitHub 搜索时切到 Code，搜 api.php/provide/vod，能直接命中别人维护的源清单。
  • 按时间排序：这类资源失效快，把结果按「最近更新」排，别按星标。
  • 看响应头：接口返回 text/html 而不是 JSON，基本是被墙或已停用。
  • 一次只验证一个：新源先在本页临时加一行测速，通过再点保存，避免整组坏掉。
  • 留意协议：http:// 源在部分网络会被拦截，优先选 https://。

各源的内容版权归属不同，公开分发与自用的法律风险不一样，请自行判断。
