这里只提供检索入口和判断方法，本站不保存、不镜像任何第三方源。点击检索词会在新标签页打开搜索。

① 影视点播源 苹果CMS 采集接口

要找的是形如 https://站点/api.php/provide/vod/ 的接口，不是网页地址。

判断能用：打开 接口?ac=list&pg=1，返回 JSON 含 "list" 或 "class" 才算通。

② 电视直播源 M3U8 播放列表

要找的是频道播放列表，或单条直播流地址。

判断能用：返回内容应以 #EXTM3U 开头；单条流用播放器试播。注意区分列表地址与单条流地址。

③ 音乐音源 LX / 洛雪脚本

这类是 JS 脚本地址，失效极快，看最近提交时间比看星标有用。

判断能用：打开应返回 JS 文本而非 404 页；链接带 @latest 或 main 的存活更久。

④ 通用检索技巧

  • 搜代码比搜标题准：GitHub 切到 Code 搜 api.php/provide/vod，直接命中别人维护的清单。
  • 按最近更新排序：这类资源失效快，别按星标排。
  • 看响应类型：返回 text/html 而不是 JSON，基本已失效。
  • 先测速再保存：新源先在点播源页临时加一行测速，通过再保存。
  • 优先 HTTPS：http:// 源在部分网络会被拦截。

各源内容版权归属不同，公开分发与自用的法律风险不一样，请自行判断。
